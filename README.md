# 🎯 I'm Bored – Activity Suggestor App

A fun, simple **Node.js + Express + EJS** web app that helps users find something to do when they’re bored!  
It fetches random activity ideas from the [Bored API](https://bored-api.appbrewery.com/) and lets users filter activities by **type** and **number of participants**.

## 🚀 Features

-  Fetches random activity ideas using the Bored API  
-  Filter by **activity type** (e.g., education, recreational, music)  
-  Filter by **number of participants**  
-  Displays a random matching activity  
-  Graceful error handling when no matches are found  
-  Built with **Express**, **EJS**, and **Axios**
